What you'll need

  • Android 14+ and a wearable app that writes to Health Connect.
  • Life Dashboard Companion, installed separately on your phone.
  • GitHub and free Cloudflare accounts.
  • ChatGPT with Developer mode, or Claude with custom MCP connections.

The guide covers Fitbit. Records available from other sources may vary. iPhone is not currently supported.

STEP 1

Generate a setup code

This protects your instance's first registration. The code is generated in your browser and is never sent from this page.

STEP 2

Deploy fitbridge

The button copies the repository into your GitHub account and creates the storage in Cloudflare. Enter your setup code when asked and keep the Workers Free plan selected.

Deploy to Cloudflare ↗

After deployment, open your Worker URL. Enter the setup code, create a passkey, and save the recovery code in your password manager.

Keep the recovery code if you move to a custom domain or lose your passkey.

STEP 3

Pair your phone

Save your time zone and data source on your fitbridge page before importing records.

Install Life Dashboard Companion 1.21.2 and allow Health Connect read, history, and background access. Set its Android battery usage to Unrestricted.

Scan the private pairing QR with the companion's pairing scanner, or use the pairing link on the same phone. This fills the webhook URL and signing key.

Select the 13 record types shown on your fitbridge page at raw resolution. Keep Active Calories and Receive off.

The companion's Send Test Ping is unsigned and will fail. Run a real sync after pairing and look for “Phone connected” on your fitbridge page.

Start with seven days. Large history imports may take several days because of Cloudflare's free quotas.

STEP 4

Connect your assistant

For ChatGPT on the web, enable Developer mode and add your fitbridge page's MCP URL with OAuth. Sign in with your passkey and approve read-only access.

For Claude Code, use the command shown on your fitbridge page. For Claude.ai, add the URL through custom connectors if your plan supports them.

How did my sleep and HRV trend over the last 30 days?

An authorized assistant can read all stored health records. Review its retention and training settings before connecting.
