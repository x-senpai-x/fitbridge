BEFORE YOU START

What you'll need

Android 14+, a wearable app that writes to Health Connect, GitHub and free Cloudflare accounts, and an assistant that supports custom MCP connections.

Fitbit is the tested source. Other sources and iOS need further device validation.

01 / SECURE YOUR DEPLOYMENT

Generate your private setup code

This page generates 32 random bytes using your browser's crypto API. The code stays in this page and is never sent to the maintainer.

02 / DEPLOY YOUR COPY

One Worker, your own account

The Deploy button copies the repository into your GitHub account and provisions D1 and KV. Enter your private setup code when asked. Keep the Workers Free plan selected.

Deploy to Cloudflare ↗

Once the build finishes, open your new Worker URL. Enter the setup code, create a passkey, and save the recovery code in a password manager.

A passkey is bound to this hostname. Recovery lets you register a replacement after moving domains.

03 / PAIR YOUR PHONE

Scan once. Then run a signed sync.

Save your time zone before importing any records. Install the separately maintained Life Dashboard Companion 1.21.2, grant read, history, and background permissions, and use its pairing scanner on your setup page's private QR.

The QR fills the URL and signing key together. Select the 13 supported types at raw resolution, as shown on your setup page. Keep Active Calories and Receive off.

The companion's onboarding test ping is unsigned and is expected to fail. Finish pairing and trigger a real sync; look for “Phone connected” on your setup page.

Start with seven days. Long backfills can take several days because your instance stays on the free write budget.

04 / CONNECT YOUR ASSISTANT

Copy the MCP URL and approve read access

For ChatGPT on the web, enable Developer mode and add your setup page's MCP URL with OAuth. Sign in using your passkey and check the assistant's name and redirect URI before allowing access.

For Claude Code, your setup page includes the exact connection command. Claude.ai users can add the URL through custom connectors when their plan supports them.

“What data do you have for the last seven days, and how did my sleep trend?”

Review your assistant's data controls before connecting. Tool responses are shared with that assistant.
